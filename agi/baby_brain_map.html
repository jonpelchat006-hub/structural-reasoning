The architecture integrates; each piece earns its place.

Rung 2 (#40): now a learning agent on a real 5×5 switching-goal gridworld, benchmarked honestly over 6 seeds. Adapting on a revisited goal, SHOVELCAT reaches it in 11.1±2.7 steps — edging out Q-learning handed the clean regime (12.3±3.0) while it must infer the regime from a noisy signature, and far ahead of position-only Q-learning (34.9). Fix (#41): Jonathan caught a flaw in rung 2 — on a revisit the agent kept going to the same first memory instead of an upgraded one, because #40 stored the first noisy sample and froze it. The top of each pillar holds the important/recent/upgraded set. To fold back into the rung-2 agent.

Fold-back (#42): folding that fix into the real agent taught us the gate. #41's clean win used ground-truth labels; the real agent must associate each look itself, and averaging a mis-matched look contaminates the prototype. Trust · stitch · the ball (#43): that gate is the truth-detector we already built (Shovelcat_29's reputation field; "Void = bandwidth for verification"). Don't replace — regression-test, then stitch; trust a memory by what it's made of, through the lens now looking.

Montage recall + the rate gate (#44): a pillar "plays a video" that must cover certain topics; because pillars blend, it cuts in scenes from other movies to fill topics it lacks — recall against an expectation of what the topic should contain. What an unknown values + neuroplasticity (#45–46): the scientist's stuck point — not knowing what an unknown target values (if we knew what a cancer cure needs, we'd have it). How the inner shell deepens — the ground-truth ladder

DESIGN

Truths at increasing depth

1+1=2 is a shallow inner truth; E=mc² is deeper, discovered further out — a higher floor of the φ-ladder. Each proven-universal gap sinks to the seabed as an anchor — a void point on the orthogonal axis, visible on the lift.

MEASURED

Swing around an anchor = perspective

Pin an anchor and rotate the frame: a task hard from one view becomes easy from another. Two overlapping streaks read 0.62 from the raw axes, 1.00 from the swung discriminant view. More anchors = more reachable views; the corpus's F1-ATPase rotary motor is the same swing around a fixed ATP anchor.

MEASURED

Cycles paint the next object

A cycle's type = its endpoint relation (A=B closed, A>B falling, A<B rising — a spinning top gives all three at once). Running the cycles deposits the swept path as a heatmap — a new object one level up — that depends on the weight (density ridge @ 1.45 light vs 0.99 heavy). Reading that deposit at a threshold is the what-for's boundary: the criterion is deposited by past cycles.

MEASURED

Does the cycle close?

Set by the spin ratio ρ=f2/f1. Rational (3/2) returns to origin at t=2 — a finite loop you memorise; irrational (φ) never closes, filling a band (near-returns only at Fibonacci times). So the verification job flips: the closed cycle's path-store saturates (finite content, error 0.035 flat), the never-closing one keeps needing new storage (~1/√B) — store its two generators instead. Rational closure also phase-locks the channels (aliasing) — why independent observers want the golden ratio.

MEASURED

A rotating ring of truths (Ophanim)

The accumulated truths sit on a ring that turns; you verify only the eyes at the gate. On N=60 truths, gate K=6: a blind wheel covers all of them over one turn but is slow on a specific violation (latency 4.5); steering the wheel to the suspected eye catches it in 1.20 steps at the same cost 6 — 10× cheaper than checking all 60. Steering the rotation is attention.

MEASURED

Perspectives carve a truth → a void point

Each memory layer is evidence; a new perspective sees separate instances with something similar between them — the invariant. As shape-from-silhouette: each perspective is a constraint, and intersecting many shaves the bounding cube (pillar face) down to the inscribed sphere (protrusion 1.26→0.002; 3D vol 32.8→4.26). A sphere reads the same from every angle (spread →0.0006) = a void point. Cross-perspective agreement = the bankable invariant; and ping-pong falls out — marginal cut →0, so late evidence is redundant and drifts to forgetting while the boundary persists.

MEASURED

Skew → a bouncing ball (approx. void point)

The flip side of the carving: a balanced cell cancels its opposites to a still void point, but we sit permanently skewed (~.14 off true zero), so the terms don't cancel and the residual circulates into a ball. Measured: skew opens a loop that misses the void (closest approach 0→0.6); as a Hopf attractor (μ=skew), μ<0 decays to the void point, μ>0 → a limit-cycle ball every start converges onto (spread 0.000) — the cell's self-loop / 1st-person POV, an off-void unanchored approximation. The true void points stay fixed; the structure moves around them. Ping-pong = that ball edge-on; it folds higher (a ball whose centre is a ball).

MEASURED

The balls are half-truths

Refines the ball: it's a half-truth, missing its opposite — residual falls 1.0→0.5→0 as the balancing opposite completes (0.5 = literally half; full = a true void point; the +/− complementary register). A void point is relational, never one point alone: with one anchor a whole direction is undefined (definedness 0), sharpening only once surrounded. And closeness to 0 = mass: as the ball balances toward the void, mobility drops 1.0→0.04 (§22.1 reuse→mass→slows→pins). The .14 skew is the gate — skewed it floats as a half-truth, balanced it sinks to a fixed anchor.

Completing a truth = the inverse triple (Erdős orchard)
